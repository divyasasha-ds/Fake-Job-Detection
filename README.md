# Fake-Job-Detection
Fake Job Detection ML project

This project is a **Machine Learning model** to detect fake job postings.  
It uses **Python**, **scikit-learn**, and **TF-IDF** to classify job descriptions as **Real (0)** or **Fake (1)**.

## **Files in this repository**
- `fake_job_detection.py` : Main Python script for training and testing the model.
- `fake_job_postings.csv` : Dataset of job postings.
- `README.md` : This file.
- `requirements.txt` : Required Python libraries.

## **How to Run**
1. Make sure Python 3.x is installed.  
2. Install required libraries:

     ```bash
   pip install -r requirements.txt

3. Run the Python script:

    ```bash
     python fake_job_detection.py


## **Dataset**
- `description` : Job description text.  
- `fraudulent` : 0 = Real, 1 = Fake.  

## **Output**
- Model accuracy and classification report.  
- Prediction for new job descriptions.
